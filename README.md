# Hyprland-3.0

## Description:
That is hyprland setup with pywal colors

## Dependencies

### Arch:
```
sudo pacman -S hyprland wofi waybar swww alacritty nvim mako python-pywal --needed
```

### Fedora:
```
sudo dnf install hyprland wofi waybar swww alacritty nvim mako python-pywal
```

## Fonts:
1.noto-fonts
2.noto-fonts-emoji
3.ttf-font-awesome
4.otf-font-awesome
5.ttf-jetbrains-mono
6.ttf-jetbrains-mono-nerd

## Installation:
```
git clone https://github.com/GeraltdDima/Hyprland-3.0.git ~/Hyprland-3.0
cd ~/Hyprland-3.0
make install
```

## Uninstall:
```
cd ~/Hyprland-3.0
make uninstall
rm -rf ~/Hyprland-3.0
```

After installation you can select your wallpaper by Mod+Shift+W and select your wallpaper to generate your pallete
Thank you!
